Read [port-victory.md at f6fd832](https://github.com/Fyntra-Development/Comet/blob/f6fd832/docs/port-victory.md), [missing-world.md](https://github.com/Fyntra-Development/Comet/blob/main/docs/missing-world.md), and [indirect-lighting-chain.md](https://github.com/Fyntra-Development/Comet/blob/main/docs/indirect-lighting-chain.md). The fork README identifies upstream cutoff [8e79c80](https://github.com/Marvisak/VIctory/commit/8e79c80); GitHub compare [8e79c80...4cbe9d7](https://github.com/Belobug/VIctory-Belobug-AMD/compare/8e79c80...4cbe9d7) returns 492 ahead, 0 behind, same merge base. These include merged side histories and carried PRs, NOT 492 unique rendering fixes. Merge [04b1a1d](https://github.com/Belobug/VIctory-Belobug-AMD/commit/04b1a1d) says upstream merged through 8e79c80, retained divergent descriptor/wave behavior, and did not merge #566/ffe310e. Cross-repository compare against current upstream main returned 404; container network DNS unavailable. This is a **partial history audit**, not an exhaustive 492-commit patch review. Latest upstream tip returned 940d32f, not the fork baseline. The connector exposes only 100 recent commits per search; supplemental searches for descriptor, texture, shader, pipeline and GPU recover older carried changes. Exact membership of the secondary leads in the post-baseline delta and whether already landed in Comet is not established. Do not port duplicates.

Every linked item credits the upstream VIctory project (Marvisak and contributors) and Belobug's fork history; both GPL-3.0-or-later, with original authors retained at each linked commit. For each real port use the brief's exact attribution, i.e. `Ported from Belobug/VIctory-Belobug-AMD <commit> <path> (GPL-3.0-or-later; VIctory by Marvisak and contributors; fork changes by Belobug)`, preserve original copyright, additionally credit individual carried-PR author, add CREDITS.md line. This note is not a port. “diff” = inspected actual commit diff; “history” = commit message evidence; “candidate” = proposed path, not inspected source path; “history lead” = carried-history candidate requiring membership, file, author and Comet-delta verification. Comet paths abbreviated relative to crates/comet-*: gpu/, shader/, formats/, hle/. Main paths lower.rs, io.rs, indirect.rs, pipeline/make.rs, pipeline/host.rs, resource.rs, descriptor/host.rs, draw.rs, formats/texture.rs confirmed to exist. Do not treat every suggested path as proven implementation identity.

Fork README: RX 9070 XT 16GB, Ryzen 9800X3D, 64GB RAM, Series X, Windows 11; 3–5 FPS, no NVIDIA validation, no ray-traced indirect, flat constant shadow illumination, missing distant trees, moving vehicle parts stretch/lag, driver timeout. Comet measured 1.09 FPS, 693 drops/frame at 4417 draws+dispatches on batch 3 default. No hardware-normalized comparison. The fork reports 225→72ms initially (2.6→3.9 FPS), final serialized-clamp mode ~80ms. These are fork-reported measurements, not Comet predictions.
