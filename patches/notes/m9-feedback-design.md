Base bb61c56b; N1 #99/#126, N5 #103/#120. Supersede (do not stack) N5's unapproved c497f8ab observation prototype; retain shared u252 space1 only if reserved/validated; use COMET_M9_TEXTURE_FEEDBACK=1, cache-keyed. ## A — translator
Comet emit/lower.rs:6511–6618 resolves Loaded/Phi/Select/Fetched/Lanes/LanePhi via heap_handle; shader.rs:391–438 clamps to real host index. Record mapping handle -> clamped index (not an atomic at handle construction); call feedback at actual image load/sample emission in lower.rs:9801–9831 and ordinary path. Exclude store/atomic/UAV, sampler, get_resinfo/get_lod. Root descriptor collision risk V1 identified: reserve a dedicated shader register space for feedback or refuse instrumenting title u252 collision; keep original bindings unchanged with switch off. Verify DXIL validator stage UAV feature flags, root DWORD count and EXEC/helper lanes before coverage claims. Atomic OR packed per index. One bit enough for positive demand; optional mip feedback must be OR-able across simultaneous samples: two-bit numeric enum is not safe (0|1 ambiguity); use 4 bits (use + mip0/mip1/lower) or a separate bitplane; unknown implicit/gradient/aniso/trilinear requires conservative all classes, not fake mip0. Exact view-relative integer load_mip class can be measured; LZ requests 0, but sampler clamp / SRV MostDetailedMip / global skip shift resource level. Do not claim requested class equals actual resident mip. True mip feedback needs hardware sampler feedback or exact effective LOD + SRV offset and footprint. Cost worst case 8m atomic updates/frame at 1080p*4; measure before wave coalescing, don't alter derivatives or EXEC.

## B — host
Per heap UAV; clear on direct queue before first valid interval, copy/reset on same queue after draws, ring of 3 readbacks; collect only completed fences, one frame later if ready, no wait. Unknown/failed/skipped/merged intervals cannot age cold. Count all bits including dynamic/relocated and invalid sink, do not attribute those to title slots. Stage 2 accepts positive title slot observations, prioritizes currently due queued entries (bounded half, preserve background, no retry override); snapshot write generations across interval or classify priority as advisory only, never evict based on it. Stage 4 needs exact canonical resource identities (address+semantic desc), all alias slots, raw copied generation, CPU tables, all queues, recorded-not-submitted protection; pin GPU-written/RT/DS/UAV/atlas/bake resources. Expose observed index/mip evidence separately from eviction eligibility. No eviction or promotion in feedback pilot. Request N5 tile/admission API after measured coverage. Two parts must be enabled together; do not enable translator before host binds.

Tests: slot bit boundary and mip class OR, shader emission root metadata and absence when off, direct/dynamic/out-of-range decode, stale generation and queue priority/backoff, ring saturation/fence behavior.
