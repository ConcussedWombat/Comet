## Evidence and port map

User-reported race leader: 270–660 s/session in >200 ms frames, almost all while new PSOs were made. Upstream [a30829c](https://github.com/avatarmanz/VIctory-7900XTX/commit/a30829c4d245467d06df7aaebddc32f8fd954a82) reports cold run shaders-1, 3,020 early PSOs, all 16 workers in expensive jobs, only 97 made in 20 s, 0.5–1.6 s frames and up to 2,900 dropped draws/frame at 60–150 s. Comet's make.rs:1–16 documents first-world >1,200 new PSOs and the >30 s title-thread watchdog. This is a plausible contributor, not proof of current black screen causality; texture/streaming/lighting can independently cause black frames.

## Procedure
1. Build gate: git apply --check patches/z13-warm-used.patch.txt; apply; cargo test -p comet-gpu z13; cargo test -p comet-gpu book_rejects; cargo build --profile diag -p comet --features diagnostics. Windows target required. Not run by Z13.
2. Record on a normal run using PowerShell `$env:COMET_WARM='1'`; reach cell and exit cleanly (used list saved by existing machinery). Files stay in local cache/pipelines/z13-book-v1; do not distribute title shader containers. Record overhead is opt-in synchronous writes on builder threads, so measure record run separately.
3. Same binary/translation switches/adapter/driver: `comet.exe warm --used` with COMET_WARM=1. Use optional --offset N --limit N to split stable sorted used keys into separate processes if memory pressure or driver hangs. Do not run warm and game concurrently (shared cache). Warm uses normal pipeline library save at end, driver cache where supported. No automatic watchdog/fingerprint skip list or all-shader command; upstream has those and this first port deliberately does not. Compiler hang can require killing the offline command; no title running. Missing/torn book entries are skipped. Re-record if schema/PSO descriptions change.
4. Compare cold cache (keep book/early history but back up then remove host-pipelines* and translated cache), cold + COMET_WARM=1 without offline warm (split only), and same cold starting cache + completed warm. Reset between trials; same camera, scene and capture timing. Keep any driver cache differences explicit; do not claim cold driver cache unless reset identically. Include off control to check no regression.
5. Log markers: Z13 warm worker split (expected 8 workers/2 slow on reference), Z13 warm start / compiling / PSO / done (made/refused/skipped/elapsed), Z13 pipeline wait (frame,key,wait_us,kind). Capture first visible cell frame token plus preceding black frames and aggregate draw/r4-grace/builder-preflight waits by token. Capture pipeline cache made/loaded, drops, device errors, loading-to-cell seconds, first-world frame duration and FPS; compare region score/texture counters. If warm succeeds but delay stays, investigate streaming/present rather than changing render output.
6. Tests cover state round-trip and owned input name, truncated description, wrong content hash, slow history parser, slow quota and promotion. Existing R4/queue tests must stay green. No rendering change intended; no local build/run or independent review yet. Offline process is separate from the game but not isolated per PSO automatically; explicit chunks are a mitigation, not parity with upstream timeout/restart.
