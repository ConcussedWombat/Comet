## Design: reclaim streaming memory without fps regression

Existing resource::let_go_idle (1432-1493) requires Arc and COM reference count one and idle time; census (1503-1545) samples first page and estimates [8]/[9], which does NOT prove whole span unmapped. descriptor/host.rs:1005 remap queue takes a global batch once, excludes recently tabled slots; 1031-1060 unmake nulls current host view and keep(index,None) retires old COM backing; 1281 keep retires against current submissions. X1 pressure-scan rotates only due entries, not every made slot. A successful upload can leave the queue and be missed entirely; raw descriptor mirroring may bypass the existing span index. texture::mapped_bytes uses endpoint/sample shortcuts, not suitable for destructive eviction. watch.rs:959/1022 provides nonblocking mapping read lock; host.rs:155 retires against currently submitted work, not necessarily previously recorded lists.

Proposed default-off COMET_N5_STREAM_EVICT=1 phase, after probe verifies substantial bytes:
- Maintain per-heap reverse map of **every** live placed texture SRV slot (including raw mirroring, all aliases and tabled slots), keyed by canonical texture identity and descriptor generation; track mapping generation and exact span. Do not infer ownership from address overlap (packed mip neighbours may overlap nominal spans). Fan remap notifications to all heaps, not first consumer.
- Runtime unmap marks candidates only; never call D3D12 inside mapper or block under descriptor/resource locks. At a queue/list safe point, rotate candidate identities under time/byte budget, validate whole retained/physical span is still unmapped with nonblocking mapping guard; partial mips remain eligible for upload. Exclude GPU-written, host-only alias, UAV/RT/depth and any unknown raw descriptor. Retry later if contended.
- Publish null SRVs and invalidate made key only after matching descriptor generation and all potentially reading lists are retired or using immutable descriptor versions. Keep old heap backing/texture until actual fence completion and no recorded list/dynamic slot can name it. Do not rely on retire(started) for unsubmitted list; use per-list Arc and heap-version lifetime or synchronized safe-point proof. No forced per-texture GPU waits.
- Requeue each slot at current generation; on remap revalidate and restore copy before first consumer. Remove staging state for old generation (W3 retained partial staging must not survive eviction). Then existing resource sweep can free only after refs drop, retaining its idle protection for host_resource borrowed pointers. Account actual freed bytes after fence, not null count. No reuse of physical heaps until fence and alias barriers.
- Prefer exact remap-driven invalidation over global polling. X1 rotating scan as fallback, cap query work and trace cutoff. Integrate N3/N6/N7 because descriptor versioning/queues are shared. Measure CPU pass, fences, rebuilds/oscillation, time to first frame, allocation failures and residency. No full eviction patch yet: raw slot reverse index and safe lifetime must be established.

## Full resolution A/B

Run baseline mip_skip=2; steps 1, 2a, 2b, 3 independently then combined; probe independent; keep all other switches and scene fixed. Then only if freed local VRAM is measured and no fps loss, mip_skip=1 and finally mip_skip=0. Capture identical world frames 120/300, black albedo, clothing/skin texture hashes and exact descriptor indices/bytes, local budget/used, waiting slots and resident refreshes, allocation count, time-to-world, steady fps and 1% low, GPU and CPU timings, device errors. No guarantee full resolution on 6.6 GB until active working set fits. If still insufficient, prioritize per-mip physical residency (a26859f tiles.rs) over raising budget/paging; mip-skip only for cold textures, promote with hysteresis; never change mip mapping without descriptor refresh and fence-safe residency. Hold any mip promotion that causes stalls, back off based on measured memory headroom.
