# R3 — Stage 4 residency design (8 GB GPU, 32 GB system RAM)

Authority: final docs/plan.md, Comet remains base (e445fd1); R3 owns host residency with N5 (#103), M9 (#111). #120 materials. Separate default-off changes; do not enable mip skip 0 globally until the cell and Gone Fishing pass. Read/write title memory and GPU-authored targets remain unchanged. Source prior art: Belobug/VIctory-Belobug-AMD 4cbe9d7 and current texpool.rs blob 0912d41964f7763fb8383a2958af17182b34751c, GPL-3.0-or-later; VIctory by Marvisak and contributors, fork changes by Belobug. Adapt only host texture allocation initially, not staging.

## 4a — Shared placed heaps
Eligible title-filled plain non-RT/DS/UAV, single-sample textures. Query allocation info with 4 KiB small-resource alignment, fall back to default alignment if rejected; use queried alignment, not assumed 4 KiB. Heap ALLOW_ONLY_NON_RT_DS_TEXTURES. Class rounded to alignment, bounded slab sizes, no incompatible class overlap. Hold heap and slot ownership until **last GPU execution using old allocation** is complete (COM reference lifetime alone is not a fence); no slot reuse/alias without proof and required aliasing barrier. Initial conservative variant uses monotonic slots; reclaim whole heaps only once no live GPU references remain, otherwise retain through device teardown. Count heap physical allocation once, occupied bytes, stranded bytes, committed fallback. 30k x (64-4) KiB = 1.72 GiB theoretical maximum, not measured; larger textures and unsupported alignments reduce this. Budget actual heap size, not sum of placed resource estimates. Test alignment/overflow/slot separation and debug layer draw→retire→new draw. W3/P4 own upload pool, N5 descriptor identity; no shared staging offsets in first patch.

## 4b — Reserved resource with mapped mips
Use D3D12 tiled resource tier check, CreateReservedResource (64 KiB undefined swizzle, eligible 2D BC, one slice), GetResourceTiling for standard mips and packed tail. Packed tail indivisible. Maintain original logical dimensions and full SRV; physical tile pool is separate from 4a small placed heap. Map via UpdateTileMappings on same queue before copies/reads, CopyTextureRegion only to mapped subresources; complete tile content from guest Layout per-mip span, exact read success, no zero fill as valid. Unmap only after last graphics/copy use completed; then tile reuse with barrier as required. Always keep a valid coarse tail. First implementation must be conservative: only use reserved resource for fully mapped test, then sparse sampling **only after** translator supplies a valid-mip clamp/fallback for all sampling/load/gather/resinfo paths. Unmapped tile reads can be zero; feedback arrives after access, so usage bitmap alone cannot prevent black first-use/LOD transitions. Explicit load must preserve coordinates, not blindly clamp; if no exact fallback, keep entire needed range resident. No shader cache changes until shader feature is defined. Distinguish logical BC mip from host mip (skip); reserved path uses skip=0 only for safe eligible resources. Mapping/valid/dirty/in-flight separate states. No tile data loss on mapping failure.

## 4c — Residency priority
DXGI local QueryVideoMemoryInfo budget/current usage with hysteresis, include render targets/reserved tile pools, staging separately. ID3D12Device1 SetResidencyPriority on ID3D12Pageable **heap** for placed/reserved backing, resource for committed. Shared slab cold only if all occupants cold. ID3D12Device::Evict/MakeResident (or Device3 EnqueueMakeResident + queue wait) on same pageable and actual fence ownership. Evict is WDDM residency management, not guarantee of system RAM placement or unlimited backing; query nonlocal budget, avoid paging thrash. Never Evict a submitted or potentially indexed resource with unknown usage; positive feedback raises priority, missing feedback is not proof of coldness. Need completed epoch plus exact descriptor generation, all heap/shader stages/explicit table reads, dynamic relocation coverage and in-flight fence pinning before eviction. Cold threshold wall-clock N seconds, budget hysteresis, low priority first; MakeResident before any new draw could use it (bindless unknown means pin or don't evict). On HRESULT failure keep state/pending request truthful; no successful residency claim based on a requested action. A frame that may sample an evicted texture cannot be submitted until residency restored or exact defined fallback. Packed/reserved tile unmapping is not the same as Evict.

## Interface / testing
M9 provides completed positive observations {heap generation, index, descriptor write generation, mip mask/class, fence epoch}; unknown/ambiguous coverage pins, not cold. N5 resolves exact live resource/backing and coordinates mapping updates, partial mip writes, recheck and descriptor lifetime. R3 owns pool, mapping plan, priority decision and fence gates; N6/queue owner verifies cross-queue completion. Stage pure deterministic planners with tests before driver calls; stage 4a independently, then 4b/4c only when lifetime and fallback dependencies are met. Test packed tails, stale generation, missing observations, pending copy, budget hysteresis, nonlocal limit, failures, no evict of shared hot slab. Log actual GetResourceAllocationInfo, heap bytes, tiles mapped/valid, priority calls and HRESULT, budget/local/nonlocal, waiting, black RT0 and exact sampled mip0 count. Matched cell + boat with current defaults vs switch; final acceptance mip skip 0 where memory allows, no black texture/garbage, ~0 waiting, no FPS loss. No game assets, no claim of measured savings until owner run.
