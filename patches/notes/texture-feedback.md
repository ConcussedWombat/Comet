# N5: GPU texture-use feedback and residency by real use

Owner N5 (#103), shader ABI coordination N1 (#99), residency #82. Source baseline main 3665afd. Benchmark owner reports RTX 5070 Laptop 8 GB / local budget 6.6 GB, raw descriptor mirror draws whole cell, 11,254 waiting at mip skip 2; skip 1 + X1 scan worsens to 17,563 waiting and 67% black albedo late; X1 releases 0 slots, ~10.6 GB title texture memory remains mapped. ## Exact translator hook / ABI (N1)

- comet-shader/src/emit/lower.rs:9485 Lower::image. It derives image source at 9540ff; image atomics at 9618 and stores at 9700 are excluded, resinfo at 9738 is conservatively use, R2 integer SRV load at 9801 and ordinary sample/gather/load at 9831 must be covered. The ordinary path subsequently emits DXIL sample/gather/textureLoad. Do not instrument descriptor parsing or scalar descriptor loads, since these may not sample anything.
- Lower::handle (6508-6618) resolves actual runtime index: Loaded via heap_index (6817; waterfall per-lane), Phi via descriptor_phi, Select via SCC, Fetched/Lanes/LanePhi via lane_heap_index (6713). Loaded handles cached per emitted block. Hook at common Shader::heap_handle in emit/shader.rs:391-438, after VIEW_LIMIT clamp, before createHandleFromHeap (218); only non-sampler SRV texture resource kinds 1..9, excluding UAV bit, buffers and samplers. This marks at handle creation, not literally once for every sample instruction: bit OR idempotent, repeated samples of the same cached handle need only one mark. Conservative extra marks are acceptable, false negatives not. Handles produced for GetDimensions count as use; helper/inactive lanes, control-flow hoisting, direct index vs table scratch slots, mesh/VS/CS and R2 integer path need N1 validation. If any path can bypass this, instrument Lower::image's executed sample/load path with resolved index (not descriptor's virtual address). Keep control flow/derivatives unchanged.
- ABI: reserve u252 space1 SLOT_TEXTURE_FEEDBACK (existing u253 faults, t254 memory, t255 strides; title root parameters limited by D3D12 root budget). TEXTURE_FEEDBACK_BITS = 2^21, fixed 256 KiB raw UAV; index clamped to 2^21-1 sink for safety. DXIL atomicBinOp.i32 opcode 78, operation OR=2, byte offset (index >> 5)*4, value 1 << (index & 31), undef remaining raw coords. Shader::root_uav_handle (326) emits annotation/root metadata; emit/mod.rs HostShader.root_uavs metadata passes slot to pipeline. Cache switch COMET_N5_TEXTURE_FEEDBACK included in comet-gpu/src/shader_cache.rs (64-82) to isolate DXIL variants; N1 verify DXIL validator/stage UAV feature flags and root-signature 64-DWORD budget (extra 2 per instrumented stage). No title-memory writeback for instrumentation.
- Host root construction pipeline/host.rs:630 recognizes internal u252 as root descriptor, not title bounded-root table. draw.rs:1495 root-UAV bind chooses current non-sampler heap, list holds bitmap COM resource, graphics or compute Set*RootUnorderedAccessView. Failure to allocate/bind fails instrumented draw (diagnostic; not suitable default-on). No shader asset changes.

## Staged host observation (COMET_N5_TEXTURE_FEEDBACK=1; no eviction)

HostHeap (descriptor/host.rs:123ff, constructor 797ff, count 949) lazily owns one Feedback per actual host view heap. Each has unique monotonic id, device-local UAV (host.rs:7523), zero upload (6690), 3 readback buffers (6651), slot last_seen CPU vector and weak global registry. Title slot range count only, ignore dynamic slots and invalid sink; never attribute dynamic table slots to title index. Explicit table consumers will need separate CPU protection (see below).

host.rs:7139 Host::present, after copy.reset and before title-to-swapchain copy at 7217: collect completed tickets (FINISHED acquire, not frame guess), record bitmap copy and zero-fill on same direct queue, then register fence returned by execute_own or synchronous execute after 7280. Device-local buffer implicitly promotes to UAV and buffers decay to COMMON at ExecuteCommandLists boundaries. Present is separate execution: COMMON -> COPY_SOURCE -> COPY_DEST -> COMMON, CopyBufferRegion to readback, CopyBufferRegion zero upload to UAV. No CPU clear while in flight. First present resets without observing unknown initial bits. Each readback ring slot reused only after corresponding fence. If all three outstanding, skip copy/reset (retain union of uses; never assume an empty observation). Collect at next present or later if fence not ready; no forced wait. Present ordering and actual flight success must be verified, including late/Relay path and device removal. Current patch observes only live heaps registered at present; destruction/missing heap and skipped presents must invalidate any coverage claim.

Logs: "N5 GPU texture feedback heap allocated" (heap/count/bytes), "N5 GPU texture feedback readback" (heap/frame/used/slots), "N5 GPU texture feedback slot-age sample" (every 60 frame numbers, number seen and observed >120-frame-old), "N5 texture feedback missing UAV; instrumented draw dropped". last_seen in pilot is slot-only and diagnostic (may over-age or under-age under merged intervals and slot reuse). No automatic admission, no nulling, no freeing, no full-mip promotion. This deliberately separates measurement from destructive policy.

## Eviction / admission policy to implement after validated coverage

1. Record identity per heap title slot: exact generation and canonical placed texture identity (address + semantic ResourceDesc; words 1/13 padding removed only under canonical switch); raw copied descriptors mirror_copied (descriptor/host.rs:1433) need equivalent identity from current raw fingerprint/record, not just slot number. Store reverse map all aliases including multiple heaps. CPU-known table reads and GPU writes update/pin by exact resource and generation. No eviction of host-written (texture.rs:545), GPU-only targets, UAV/RT/DS, unknown backing, bake sources/targets or sampled depth twins. Keep tabled/dynamic views protected by existing list refs. Initial bake can run before any completed feedback; keep pre-bake upload policy, pin bake sources until bake completes.
2. At completed **coverage epoch**, join bitmap slots with identities from the executed descriptor generation. Bindless descriptor contents can change between recording and execution; snapshot generation at submit, mark both generations if changed while work in flight, or invalidate that epoch. Do not age when shader translation/PSO failed, missing/overflowed/unbound feedback, unknown direct handle path, ring skipped, lost present, partial multi-heap coverage, or unobserved list. Distinguish CPU frame number from GPU completion; skipped reset may union multiple frames but cannot prove inactivity individually. Union per identity across slots/heaps + table uses; late observations never decrease last_seen. Start no-eviction observation for >=120 completed contiguous epochs; initial N=120 completed frames (not wall time), configurable COMET_N5_TEXTURE_COLD_FRAMES; set at least 2*N hysteresis for promotion/demotion experiments if needed. Never evict merely because slot not in queue or title pages mapped/unmapped.
3. On pressure only, reclaim cold title-filled placed resources in bounded batches (e.g. 32 identities / 32 MiB per frame, target 10% budget headroom, not exceeding measured slack). Cold = no use for N completed, fully covered frames and no outstanding recorded/submitted consumer; pin recent writes, recent descriptor rewrites, pre-bake inputs, tabled uses, in-flight lists. Prefer largest cold allocation, then oldest; don't invalidate an entire heap. Maintain actual per-resource bytes and count once across aliases. Re-read generation immediately before nulling. Unmake all alias slots with type-compatible null_for and clear made/copied/raw cache identity or mark dirty so remirror can rebuild; release kept COM refs via existing retirement. **No descriptor mutation while GPU may read**; submit safe point in host.rs:4826-4865 when no flights, plus recorded-not-submitted list protection/immutable heap version or generation pin. retire at host.rs:155 protects started submissions only. Do not bypass resource::let_go_idle (1432) Arc/COM ref and borrowed host_resource lifetime checks, don't forcibly free in-use resource. Old descriptors must never retain freed GPU addresses. Use bounded scan X1 cursor if needed, not mapping probes. Actual freed bytes counted after completion, not estimated nulls.
4. Keep logical view identity when null (and do not remove title descriptor). Shader records index even when its host slot is null; a typed compatible null SRV yields zero, so miss becomes high-priority admission on next complete feedback. Keep high-priority requested set separate from 11k background queue; promote at most budgeted bytes/time, charge actual allocation size. Source title memory still mapped (benchmark evidence); build full-resolution host copy (skip=0) for hottest/missed slots first, not global skip=0. Update mip offset/SRV format per resource and all alias slots atomically at safe point; invalidate W3 staging on copy generation change, and reupload before descriptor becomes visible. Preserve current texture until replacement published; if overlap allocation cannot fit, evict other cold copies first. A null miss can cause one-frame texture pop; use lower-mip fallback or reserved-tile residency (hyphennn a26859f) when feasible, never force synchronous waits. Background requests under pressure stay low resolution or null; no thrashing: recently promoted pinned >=N frames, downgrade only sustained pressure, reserve room for GPU-written targets and buffers. If active full-res set exceeds physical budget, full resolution for all active textures simultaneously is impossible without compression/reserved mip residency or paging; don't fake target.
5. Compare current baseline skip=2 against feedback only, then eviction-only with existing skip, then adaptive full mip promotion. Monitor GPU wait, total prepare, texture uploads, actual local VRAM and shared use, misses/pop-in, frame times and black albedo. Stop on regressions or validation errors. Keep policy default off and separate from measurement flag. No default-on until before/after captures.

## Cost estimate (not measured)

- 2^21 indices / 8 = 262,144 bytes = 256 KiB device-local UAV/heap. Three readbacks plus zero upload = 1 MiB host-side GPU allocations per heap, total 1.25 MiB/heap before metadata. CPU last_seen uses 8 bytes/title slot (~7.6 MiB at 1m slots). Per snapshot 256 KiB GPU->readback + 256 KiB upload->GPU = 512 KiB transfers/heap; 30 fps = 15 MiB/s, 60 fps = 30 MiB/s (2 transfers, not an extra wait); at ~1 fps 0.5 MiB/s. CPU scan at most 65,536 words; ignore title-outside indices. At 1m slots roughly 31,250 words, set-bit walk proportional to unique used slots. Snapshot ring overhead is small relative to 6.6 GB, but command/barrier cost and map overhead must be measured.
- Shader cost dominates: per executed handle creation, one atomic OR plus ~5 integer ops and optional clamp. Worst-case naive per sample at 1920x1080 and 4 samples/pixel = ~8.29m atomic ORs/frame before overdraw; 8x overdraw -> ~66m. Same texture index/word can cause severe cacheline contention; no FPS-neutral claim. Baseline diagnostic is deliberately unaggregated. N1 optimize wave-uniform indices (one active-lane leader OR) only with proof of full active lane coverage, use wave match/ballot or group equal *word* indices and OR masks on SM 6.6, preserve nonuniform resources and helper semantics; don't use WaveSize64 on NVIDIA. For uniform 32-lane waves, potential reduction up to 32x (8.29m -> ~259k). Divergent worst-case unchanged. Consider coarse spatial sampling only as separate quality experiment, never use sampling false negatives for destructive eviction. Compare GPU timestamp draw cost + end-to-end fps on reference card. User target no FPS loss; if cost too high optimize or disable feedback before eviction.
- Request N1 validator pack, root signature budget and instruction coverage: known decoration bake pixel hashes c0a7fe77b1862e10, 0d1575a396dfe513, b7cfd8dda91ebb6b, 280967ad158cee0b (source c96b4f2; not independently confirmed in current captures). Offline test a synthetic sampled texture with known indices 0,31,32, high slot, nonuniform lanes, branch/select/phi, integer load, table and heap; verify exact bitmap and no writes for sampler/buffer/UAV, same output bytes. Include multiple frames, outstanding readbacks, descriptor rewrite and heap destruction. Verify UAV metadata/dropped PSOs, debug layer and GPU-based validation; if shader emits unsupported stage UAV or root signature >64 dwords mark coverage incomplete, no eviction.
