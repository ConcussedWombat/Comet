## Evidence, not a proved visual cause

User reports Lucia's translucent doubled orange face edge, doubled window fence, blocky stair-step silhouettes in the opening cutscene. These are consistent with missing temporal reconstruction or incorrect reprojection/history, but also with pre-resolve geometry/refraction/lighting and the known lowest-LOD streaming problem. The checked-in evidence-cell-999243c.md has G-buffer and geometry hashes, not an identified temporal resolve, velocity or jitter register. No retail/game capture available here. Do not conflate screen-probe temporal resolve (indirect lighting) with screen-space AA.

## Staged change

`patches/z8-accc-upscaler.patch.txt`, default off; DXIL takes precedence. COMET_Z8_ACCC=1 is intentionally a **probe**: parse/translate actual ACCC-only shader, log decoded layout and emitted DXIL size, then return an error before making a host PSO. Existing dropped-dispatch behavior retained; no GPU work from ACCC. COMET_Z8_ACCC=run is explicit live experiment, not recommended until every required pass is translated/validated, resources matched, and build gate agrees; partial dependent dispatches could give worse history or GPU hang. No title assets or external shader bytes in patch. Switch in shader_cache.rs build key. Existing shader failure handling remains, no fake data. Parser synthetic tests cover wave/group, raw/prefixed code, resource slot, zero stride, malformed ranges/duplicate/truncation and DXIL precedence/default-off. No build or game run by Z8; tests not executed. Exact shader hashes must come from benchmark log.

1. `L3 FSPX candidate` + `first bind` + `Z8 ACCC decoded` (hash, layout, used, numthreads) + `Z8 ACCC probe emitted; dispatch remains disabled` OR actual translation error. Distinguish created vs first bound vs recorded dispatch; `DROPPED` + roots in frame ops, and actual successful dispatch names if fallback path exists. Keep exact error and hash.
2. In each adjacent frame, identify last full-screen colour producer and consumers, candidate 2-channel motion/depth/color/history input/output by SRV/UAV slot, dimensions, format and guest/host resource identity; check producer before consumer, clear and history ping-pong across both frames. Root constants from capture ops (bounded words) and root CBV address/size, not guessed offsets; correlate with camera movement and cut. If velocity is absent, distinguish no producer from zero output. Dump velocity, pre-resolve colour, history input/output, final image; retain on owner machine. Existing ops only show bound host pipeline resources; for dropped shader use decoded slots and existing dropped roots, additional descriptor mapping may be needed.
3. If no ACCC first bind/dropped dispatch in the scenes, don't enable live path; pursue actual fallback resolve with M3/L5/L6. If ACCC is in chain but any pass fails CPU translation/validator or resource mapping, do not enable run. If all pass, build gate/owner decide whether to use explicit run experiment with matched control; compare cell window/face edge ghosting, cutscene silhouette quality, FPS, untranslated/refused/dropped, no GPU/device errors; stop at first regression. Report actual log lines and hashes. No claimed FPS or accuracy improvement yet.
