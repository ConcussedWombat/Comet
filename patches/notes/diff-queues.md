## Stage priority
Reserve event ticks without changing queue, swap chain, frame rate, or W5 locks. Ensure clock reset reads LAST under the same lock only with the switch enabled; leave successful old late-wait behavior when switch off. Test deterministic distinct claims, timeout no reservation, catch-up and normal sequential ticks; Windows build/Clippy/test gate. Source proof is a race opportunity, not proof of post-W5 bug. If no concurrent same-kind waits in trace, expected no menu benefit; keep default off. Next higher-risk ports: per-queue present FIFO and mapping order; separate review and capture.
