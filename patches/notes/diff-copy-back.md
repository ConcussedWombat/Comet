# N6 — Copy-back and title memory delta ledger

Plan e8150c7; issue #104; helpers W4/W5. Baseline supplied by benchmark owner: ~560 ms GPU wait and ~110 ms copy-back per frame, ~0.9 fps. No game run or compilation by N6. Line numbers below are against Belobug 4cbe9d7 (B), fxceless/victory-fork a26859f (H), 9376fd6 for the in-flight fetch (HF), and inspected Comet main (C; shadow blob 6fc92f32748917d0fe4fc0f1eae21e5192d05ef7, watch blob 29668f64712b70e01b735f2181bc7d26e777fab7, host blob 719172698443ecca20740942db28698da901f012). Paths relative to crates/{victory,comet}-gpu/src. This is a functional-path comparison, not a claim of exhaustive line-by-line equivalence across the three forks.

## Capture / acceptance

Benchmark owner: same cell route, capture baseline and COMET_WATCH_ADVANCE_EPOCH=1 (COMET_ASK_ONCE=1 both, same Relay/cards switches and texture settings), at least 60 steady in-world frames and identical frame IDs/screens if practical. Capture the N6 epoch log, FPS, total GPU wait, copy-back time, bytes refreshed/compared, card fetch waits and settles by cause (especially stale pending ranges), device errors, menu flicker and image/depth regression. If no N6 log, no eligible known copy ran; do not claim activation. No title shader hash exists for this CPU change; CARD_COMPARE/CARD_FETCH are internal GPU memory passes, not a translated game shader. No hash-to-symptom attribution without capture.
