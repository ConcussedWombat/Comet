## One staged idea
With switch on retain pre-merge scratch and write only changed runs via existing kernel-checked write_mapped. No stale gap stores; never widen to a full word if that might restore a CPU byte. Watch::writing once for the piece, as before. With switch absent/0 same old span write and no scratch clone/counters. Unmapped behavior unchanged; no shader/cache changes. Stats count requested bytes, not successful kernel writes. Same-byte races remain; no claim that all relay corruption is fixed. Multiple kernel calls could be slower than the old single call. No fallback widening. GPU wait/PCIe fetch bytes unchanged.
