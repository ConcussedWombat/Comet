## Shared ABI and implementation gates
N5 #103 owns staged observation, N1 #99 shader ABI: u252 space1, 2^21 bits per heap, ring of 3 readbacks. Do not duplicate. N5 patch lines 207–368 diagnostic slot age explicitly not eviction proof. M9 positive priority API accepts queued write generations snapshotted before execution, matches exact generation, respects retry due times, bounds priority to half the service; only positive uses count. Default-off COMET_M9_TEXTURE_PRIORITY; needs N5 producer hookup. No destructive behavior until:
1. All queues/heaps/stages covered; first clear established, complete successful fence intervals; merged, skipped, partial, failed intervals cannot age cold. Snapshot exact slot generation at submit and invalidate if changed in flight. Canonical resource identity = title address + semantic desc; union all alias slots including raw fingerprints and CPU table uses. Unknown, GPU-written, UAV/RT/DS, bake/atlas and recorded/in-flight inputs pinned.
2. >=120 complete contiguous epochs, actual pressure and bounded reclaim; recheck generation and absence of recorded/submitted readers before type-compatible nulling of all aliases. Preserve title descriptor, invalidate made/copied state for remirror, use existing COM retirement/sweep. Count actual reclaimed bytes, not nulls.
3. Admit positive null misses before background. Retain lower-mip fallback when possible; full-mip replacement must fit actual budget including overlap, upload before publish, atomically replace all alias SRVs with correct mip offsets. Active set may exceed physical budget; no guarantee of simultaneous full res. Separate reserved tiles port.
