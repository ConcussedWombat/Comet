## One staged idea: COMET_Z11_EXPOSURE_PROVENANCE=1 (default OFF)

Carry per-copy source identity, width, exact box, destination x, W6 fix state, recording presentation epoch, unique sequence ID in deferred entry through Map and CPU publication. Preserve raw little-endian u32 float words, including signed zero, NaN payload and infinities. No new readback, waiting, barrier, shader or value modifications, no global destination-address lookup. The struct increases deferred entry size even with switch off, but default readback values and ordering unchanged. Off produces no Z11 logs. On can expose timing perturbation from logging; don't use FPS from diagnostic run as performance win. Presentation epoch is not a GPU fence, nor proof title CPU consumed values. Existing W6 detection is reused (RGBA32F 1x1 or 5x1 subresource zero, one row). It identifies candidates, not title shader names; correlate actual passes. Legacy W6=0 retains its previous copy semantics, so partial or uninitialized legacy data may be visible, not corrected by trace. All logs listed below are EXPECTED, not observed.

- Z11 exposure recorded: id, recorded, src, width, source_box, x, fix, dst, bytes (after recording copy, before deferred publication).
- Z11 exposure published: same id, recorded, published, src, dst, bytes, words (only after CPU copy, exact bytes published).
- Z11 exposure map failed: same id, recorded, published, src, dst, bytes. A recorded ID without either may be unsubmitted/reset, not automatically a lost GPU request.
- Unit test z11_metering_words_keep_nonfinite_payloads: raw bits for 1, -0, +Inf, NaN payload. Existing W6 partial-window tests unchanged.
