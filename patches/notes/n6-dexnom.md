## Integration / gates
This is a cross-module feature, not a drop-in shadow.rs patch. Stage N6 consumer separately; N1/N2/N3 must stage producer, root bindings and certification. Producer must declare all potentially-written spans and call marked declaration only for writes proven marked (including no host clears or other uninstrumented writers to same shadow). Never use an all-zero bitmap as proof without a certificate. Initial consumer runs only when late/Relay is off, no GPU in flight and fence is verified. Keep snapshots as fallback; per-flight bitmap and first-write saving are follow-ups. If no certified path is exercised, switch changes no merge/scan decisions; no performance gain may be claimed. Request A/B on same scene/draw counts, exact bytes vs full scan, no missed writes, GPU wait/copyback/snapshot/mark overhead, screenshots/depth, device removal. No title shader hash assigned before producer capture; request actual hashes of instrumented pipelines from N1. Credit both commits in patch and CREDITS.md.
