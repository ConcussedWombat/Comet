## Measurement and acceptance

The plan's 22 is a scoreboard label; the table names 16 actual translation failures (6 descriptor PS, 3 interpolation PS, 3 divergent first-lane CS, 1 permlane CS, 2 f64 CS, 1 address/format CS), 5 refused compute PSOs and a refused mesh/PS pairing, plus f133e35efed2a48a separately. Do not combine these as confirmed translation failures. Fork reports 14 additional translations and 59/64 trace programs, not evidence Comet hashes match or that ray tracing lights this room. a26859f README also attributes correct first room to descriptor mirroring, buffer own-copy and memory residency changes. No measured connection from any of these shader changes to absent walls/floor or bunk zero albedo yet. G1/N2/N4 own PSO/culling attribution; L2/G3 builder crash. Benchmark owner: offline per-hash fresh process --validate and pipeline creation, capture matched baseline/candidate post-mip-skip with COMET_CAPTURE=<dir> COMET_CAPTURE_WORLD=1 COMET_CAPTURE_WORLD_ALSO=120,300 COMET_DUMP_TARGETS=1; preserve builder/ambient/relay settings.
