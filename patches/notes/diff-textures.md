## Measured baseline / evidence boundary

e82716d mip-skip reduced waiting from 15,350 to ~2,500 and black albedo from 81% to ~40% (plan). User reports ~4 min loading, 250 ms cutoff. 8 GB RTX 5070 Laptop; reference GPU budgets differ. No individual material shader hash has been linked to a remaining waiting texture. The pass is draw.rs:1931 State::heap_textures, not a shader translation. Existing log: "textures picked by index: the card has no room for more; they wait" (draw.rs:1961); "background bindless texture scheduling budget" (566); HEAP_TEXTURES_WAITING/QUEUE/FULL, phase timing counters (530-640). Missing-world.md reports material PS 7d0f14ce44746d7e and 6b6db9f1a526daeb as translation failures, NOT proved texture misses. Do not claim those fixed. Walls absent from depth cannot be diagnosed from black albedo.

## Order / capture

1. Stage target headroom (H resource.rs:1416-1476), independently tunable, unset = exact old path. On 8 GB test 1024 MiB then 2048 only if target census warrants; reference 3072 is not assumed suitable. Explicit COMET_TEXTURE_BUDGET_MB keeps precedence. No buffer reserve until P4/N6 quantify pending buffers. This is the smallest independently testable reference change, not an allocation-speed fix.
2. Shared heaps as priority allocation port after the lifetime/alias barrier audit, staging pool separately. Collect allocation count/latency, logical/physical bytes, slab utilization, fallback count, device errors, resident texture count.
3. Levels on demand after queue and descriptor coordination; capture mip masks, mapping counts and copy order.

Benchmark owner: same main, COMET_TEXTURE_MIP_SKIP unchanged, default vs COMET_N5_TARGET_ROOM_MB=1024. Use COMET_CAPTURE=<dir> COMET_CAPTURE_WORLD=1 COMET_CAPTURE_WORLD_ALSO=120,300 COMET_DUMP_TARGETS=1. Provide first-world and 120/300 frame local budget/usage, target bytes (HOST_TEXTURES[1]-KINDS[1]), pending slots/queue/cutoffs and phase timings, time-to-first-world and time-to-textures-stable, fps and device errors; ops trace for Lucia clothes, bunks with normal but zero albedo (PS hash, SRV address, resource/descriptor and mip residency). No shader hash inferred. New log "N5 texture target headroom active" and transition "N5 target headroom texture admission" prove switch and gating. Reject if default differs, or reserve worsens texture stability without preventing measured target/buffer pressure.
