## Single staged idea
patches/z9-blur-cbv-trace.patch.txt, COMET_Z9_BLUR_TRACE=1, default off. Diagnostic builds, existing listed capture frames and capture folder only. Inline Z9_CBVS marker beside exact stage hash and root slot or table root + DWORD offset in frame-N-ops.txt. Samples first up to 256 bytes of guest CBV as little-endian DWORDs, bounded to complete words and declared table size / shadow remainder. Root CBV has no explicit descriptor size; bound to mapping, not inferred logical size. Guarded nonblocking title-memory read and existing kernel reader; unreadable => None, never fabricate zeros. No changes to shader, cache, render targets, history, velocity, focus or image. Actual GPU constants may differ due to deferred uploads, and constants beyond 256 bytes/dynamic bindless/placed buffers are not sampled. No additional GPU readback or submission. Diagnostic capture overhead may affect pacing; do not use this run for FPS acceptance. Unit test z9_cbv_sample_bounds_and_words covers truncation, bounds, little-endian and partial words. Not built or run by Z9; build gate #43 needed.

## One-run capture request
Diagnostics build with this patch applied. Same camera/profile, existing texture/lighting/temporal switches fixed. Set COMET_Z9_BLUR_TRACE=1, COMET_CAPTURE=<new folder>, COMET_DUMP_TARGETS=1, COMET_CAPTURE_FRAMES=<known frame numbers in this run> (use COMET_CAPTURE_WORLD and COMET_CAPTURE_WORLD_ALSO offsets if scene-relative targeting is necessary). Select a late cell frame with player in control stationary at the window, adjacent stationary frame, one deliberate camera pan frame, and one cutscene focus-change frame if practical in the same launch. Record full-resolution screen captures (not upscaled diagnostic PNGs) with matching scene/timing and return ops, raw log timestamps, and target dumps; no game assets committed. Capture one representative frame in PIX/GPU debugger if supported: raw values at each candidate writer/consumer event, not only end-of-frame images. If PIX not feasible, send ops + Z9_CBVS + target dumps first; Z9 will identify hashes for targeted raw probes.
1. Walk backward from final scene composite (not HUD) through full-res and half-res color targets. For each candidate record actual pixel/compute hash, dimensions, viewport/scissor, target/UAV identity, producer and consuming SRV identity and format/subresource. Match exact resource identity and queue submission order, not merely dimensions or recording-order lines. Look for depth-dependent CoC generation, near/far blur gathers, directional velocity gather, then composite; verify by disassembly, not by assigning names to sizes.
2. Record raw depth samples at wall/bunk/window/player; determine from projection/assembly if reversed-Z/infinite-far and actual near/far/linearization coefficients. Compare shader reconstruction to view-space depth at known pixels. Record CoC signed radius and focus distance/range/aperture constants with DWORD offsets and actual shader binding; static gameplay should not give large radius for all background unless title intentionally requests it. Check if wrong depth view, cleared depth, bad constants or wrong arithmetic explains it.
3. Record signed raw velocity vectors on stationary opaque background and moving silhouette, plus pan. Compare to previous/current transform and jitter removal (Z8), resolution in pixels vs UV and temporal scale/time delta. Large coherent velocity on static geometry indicates reconstruction/history problem; directional streak growing with camera pan indicates motion blur. Preserve intended gameplay motion blur and cutscene focus behavior.
4. Confirm half-res target actual dimensions and mip/view against shader UV step, reciprocal resolution and dispatch size. A factor of two or stale/reused source must be proven via actual constants and event bindings; half-res alone is normal. Distinguish coarse material mips: if pre-post color already soft with sharp geometry/depth, route to N5, not DOF.
5. Compare local non-window bunk/poster/wall edge contrast or 10–90% edge width at equal full resolution before/after each stage. If pre-DOF sharp but DOF output soft at rest with large CoC, fix exact depth/focus feed. If velocity is wrong at rest, trace producer with Z8 and fix exact unit/transform; if CoC/velocity valid and TAA output first soft, hand to Z8. If soft already before blur, M3/N5 investigate. Measure final scoreboard cell wall/poster region and check no loss of window distortion, intentional cutscene DOF, HUD or device stability. No blind global blur disable, arbitrary near/far, velocity clamp or sharpen.
