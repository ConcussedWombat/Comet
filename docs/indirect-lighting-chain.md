## Concrete breakpoints in Comet

- pipeline.rs Builder/of_builder/builder_runs: classifies spilled native compute programs; every created builder PSO must exist. A later stage failure disables rest of run (not rollback of recorded work). COMET_BVH_BUILDER=1, COMET_BVH_QUARANTINE=0 for acceptance; quarantine prevents title copyback of counters/headers and is diagnostic only. L2 owns builder, L4 first-EXEC-lane fix, L9 exact semantics.
- draw.rs dispatch/execute_indirect: missing PSO, skip flags, incompatible signature, missing arguments/count ranges, bind failure or clamp can drop work. Indirect args read host copies after earlier writes then bounded into scratch; compare actual active counts, not merely recorded dispatches. Indirect tiled-lighting rectangles without geometry stage can draw only half a rectangle; identify whether apply uses this path before R4 fix.
- draw.rs bind/tables/host_word: missing root values become zero, absent buffer-view address returns zero, descriptor slot exhaustion drops work, missing root UAV can be null, direct root descriptor may remain unset. Compare actual table dword/slot. W3/R3/L1 own textures/stale descriptors; R2 material/stencil. Null UAV is not valid output.
- **Static gap staged:** lower.rs view_address emits USER_VIEW_ADDRESS low/high from a static aligned buffer SRV/UAV descriptor. draw.rs host_word resolves the title buffer address via original table and buffer_range. memory_ready previously only names root views and heuristically interpreted root constants. Descriptor-derived raw pointers can therefore reach otherwise unprepared pages even when the normal descriptor is bound. This is a source-level gap, NOT yet an observed failure of f22a76fcb967ee59. Candidate names exactly those emitted addresses, not guessed descriptor words; cannot resolve pointers subsequently loaded on GPU or guarantee full large-allocation coverage.
- memory.rs: 64 KiB directory entries, host raw-UAV heap (1023 numbered copies + null), root view/heuristic root constant/next 4 MiB window preflight. Absent read returns zero, store disappears; hashed fault notes serviced next frame. Collisions and first-50 warning limit mean logged pages are lower bound, not per-pass exact counts. Builder with missing pages is semantically incomplete even when recorded. Pointer-chased instance/header/geometry pages, overlapping shadows, one-time entries, exhausted copies, partial commitment, per-list newly numbered copies and cross-list ordering all require checks. Existing code admits copies numbered by another list may not be refreshed here. Don't blindly map every page or ignore failed stores. Relay OFF baseline; W5 owns flight dependency.
- lower.rs memory_with_presence: null raw UAV and fault note on absent page; BVH lowering explicitly checks presence and wide-node boundary. Generic raw loads may consume zero as real data. Valid miss/empty node differs from absent page. Both halves of wide nodes must be present. Keep R2 slab default; L9 reviews exact rounding/order. L5 descriptor-as-data, L6 interpolation and L7 VALU fixes may affect chain; actual hashes must be matched. R4's four refused compute PSOs 02384a60fda6f2d0, 369cbe906ea72764, 2cc4c197ee29e291, 2da4beb386509b77 remain unclassified. L3 recovery may recover unknown producers, not DXR evidence.
